# Social factory
Source-backed drafts → brand/rights/fact review → channel-specific creative → accessible caption/alt/subtitles → timezone calendar → immutable campaign hash → scoped approval → provider scheduling → delivery readback → attribution → measured improvement.
Every item binds tenant, business, channel/account, content/media hash, URL/UTM, scheduled timezone/UTC, campaign approval, idempotency key and provider receipt. Approval requires exact schedule window and channels; content changes invalidate previous approval. Default mode DRAFT_ONLY. Paid generation and publishing require existing explicit scope/budget. Polling uses existing supervisor; STOP cancels future jobs. Retry only when provider receipt reconciled. Do not fabricate followers, comments or rankings; platform capabilities/policies are verified at execution.
