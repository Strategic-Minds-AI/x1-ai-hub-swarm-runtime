# Independent quality and scaling
X1 targets are not Google mandates. A >=99% visual score must define changed-pixel calculation, color delta tolerance, pinned renderer/fonts/DPR, deterministic dynamic data, reference hash and explicit masks before running. Every required viewport/state passes separately; overall averages cannot hide failure. Pixel parity does not measure operational completeness.
Operational score = passed applicable required checks / all declared applicable required checks; denominator must be positive and frozen before run. Independent actor confirms exact artifact and tests; absent evidence remains UNKNOWN. N/A needs rationale. Browser tests, screenshot results, real API/queue execution, recovery and deployment tests must not be substituted by mocked unit tests.
Batch sizes are finite with approved maximum, cost, provider quotas/concurrency and fulfillment. Public page eligibility is reviewed per intent/entity, not Cartesian city×industry×language multiplication. Duplicate intent merges. Scale after real impressions/leads/sales/revenue/cost evidence; repair or stop losers. Prioritize profitable user value, not domain volume.
